# Результаты

[`results.json`](results.json) содержит принятый прогон для раздела 4.
Указаны версии среды, SHA-256 исполняемого файла, исходников решателя
и каждого сериализованного входа. Семь замеров каждого вызова сохранены
в поле `cli_ms_samples`. Поля без результата для неоптимальных задач
записаны как `null`.

Контрольные суммы исходников относятся к фактическим байтам рабочей копии
Windows, из которой собирался CLI в WSL. Они могут отличаться при другой
настройке окончаний строк. Контрольные суммы сериализованных входов
воспроизводятся независимо от окончаний строк в рабочей копии.

Для воспроизведения используйте [команды сборки и запуска](../../README.md)
с семью повторами. Таблица по размерам строится по пяти задачам
`dense-N-*` на каждый размер `N`. Для времени берётся медиана
`cli_median_ms` по пяти задачам, для численных расхождений максимум
`max_violation` и `objective_abs_gap`. График использует минимум, медиану
и максимум `cli.iterations`. Время зависит от компьютера и его загрузки.
