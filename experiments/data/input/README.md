# Входные данные

Контрольные задачи хранятся в формате LP1. Оптимальные значения и
статусы дополнительно сверяются с SciPy/HiGHS при запуске экспериментов.

| Файл | Происхождение и назначение | Ожидаемый результат |
|---|---|---|
| `worked-example.lp` | Учебный пример из раздела 1 отчёта | Единственный оптимум `(2, 2)`, цель 10 |
| `negative-b.lp` | Минимизация с нижними границами `x1 + x2 >= 3` и `x1 >= 1` | Оптимум `(1, 2)`, цель 4 |
| `infeasible.lp` | Противоречивые границы `x1 <= 1` и `x1 >= 2` | `infeasible` |
| `unbounded.lp` | Максимизация `x2` при `x1 <= x2` | `unbounded`, луч `(0, t)`, `t >= 0` |
| `degenerate.lp` | Пример Била из книги B. Kolman, R. E. Beck, *Elementary Linear Programming with Applications*, 2-е изд., с. 127. Добавочные переменные устранены | Оптимум `(1, 0, 1, 0)`, цель 1 |
| `multiple-optima.lp` | Максимизация `x1 + x2` при `x1 + x2 <= 1` | Цель 1 во всех точках отрезка `x1 + x2 = 1`, `x1, x2 >= 0` |
| `scaled.lp` | Первые две строки примера из раздела 1 умножены на `1e-6` и `1e6` | Единственный оптимум `(2, 2)`, цель 10 |
| `no-constraints.lp` | Минимизация цели с положительными коэффициентами без строк ограничений | Оптимум `(0, 0)`, цель 0 |
