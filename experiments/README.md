# Вычислительные эксперименты

Зона ответственности агента 4. До утверждения внешнего формата здесь хранится
только структура, без вымышленных данных и результатов.

Предлагаемая организация после согласования:

- `scripts/` — воспроизводимые сценарии запуска и анализа;
- `data/input/` — небольшие версионируемые входные наборы с происхождением;
- `data/output/` — только принятые результаты, необходимые отчёту;
- `figures/` — генерируемые изображения для последующего переноса в отчёт;
- `requirements.txt` — зафиксированные версии реально используемых пакетов.

Каждый эксперимент должен фиксировать версию/commit приложения, параметры,
seed генератора, окружение, точную команду запуска, эталон и критерий сравнения.
Сценарий не должен зависеть от абсолютного пути пользователя.

Python-окружение создаётся локально и не коммитится:

```bash
python3 -m venv .venv
source .venv/bin/activate
# После появления зависимостей:
python -m pip install -r experiments/requirements.txt
```
