# Вычислительные эксперименты

Сценарий сравнивает `simplex_cli` с методом внутренних точек HiGHS
через SciPy. Прогон включает восемь [контрольных задач](data/input/README.md)
и двадцать сгенерированных задач. Зафиксированный прогон и его параметры
описаны в [результатах](data/output/README.md).

## Воспроизведение

Выполните из корня репозитория. Нужны CMake, компилятор C++20 и Python
3.11–3.14. Ниже команды для Linux и WSL.

```bash
cmake -S . -B build/release -DCMAKE_BUILD_TYPE=Release
cmake --build build/release --parallel
python3 -m venv .venv
.venv/bin/python -m pip install -r experiments/requirements.txt
.venv/bin/python experiments/scripts/run.py build/release/simplex_cli \
    --output build/experiments/results.json
```

В Windows используйте `.venv\Scripts\python.exe` и укажите путь к
`simplex_cli.exe` из выбранной конфигурации CMake. Python и исполняемый
файл должны запускаться в одной среде, чтобы таймер не учитывал запуск WSL.

## Критерии проверки

- Статусы программы и HiGHS должны совпадать с ожидаемым статусом.
- Для оптимального плана проверяются неотрицательность и ограничения
  `Ax <= b`. Максимальное абсолютное нарушение допускается до `1e-7`.
- Значение цели проверяется подстановкой плана, сравнением с HiGHS
  и, для контрольных задач, с известным значением. Для каждого сравнения
  допускается разность до `1e-8 * max(1, abs(эталон))`.
- Для одного входа решение и число поворотов должны совпадать во всех
  запусках. По умолчанию после первого вызова измеряются семь отдельных
  запусков CLI. Время включает запуск процесса, передачу входных данных,
  решение, получение и разбор JSON.

Генератор NumPy с начальным состоянием `20261108` создаёт пять задач для
каждого размера `n = 8, 16, 32, 64`. Сначала он выбирает допустимую точку,
затем формирует `n` плотных неравенств с положительным запасом,
`n` покомпонентных верхних границ и ограничение `x1 >= 1`.
Поэтому все сгенерированные задачи совместны, ограничены и имеют
`m = 2n + 1` строк, включая отрицательную правую часть.
