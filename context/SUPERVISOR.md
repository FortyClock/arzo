# Контроль проекта

2026-11-08. Ветка `feature/complete-simplex-project`, база `ee6690e`
с первичным аудитом `5eeb8de`.

По запросу пользователя в одной ветке подготовлены программа, тесты,
эксперименты и отчёт из пяти разделов. Первый раздел содержит постановку,
сравнение четырёх методов и проверяемый пример. Программа на C++20 решает
этот пример и задачи с отрицательными правыми частями. Результаты
сопоставлены с независимым решателем.

Команды сборки — в [README](../README.md). Состояние компонентов и
результаты контрольных запусков — в [INTEGRATION.md](INTEGRATION.md).
Оставшиеся действия для сдачи — в [BLOCKERS.md](BLOCKERS.md).
