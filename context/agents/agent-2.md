# Журнал агента 2

Роль — алгоритм симплекс-метода, его вычислительное ядро и раздел 2 отчёта.

## 2026-11-08

- Реализован табличный двухфазный алгоритм в `src/simplex.cpp`. Входные
  строки масштабируются степенями двойки, при отрицательной правой части
  вводится искусственная переменная. Выбор ведущих элементов выполняется по
  правилу Бланда. Лимит охватывает обе фазы и очистку базиса.
- Подготовлен `report/sections/02_algorithm.tex`. В разделе описаны
  преобразование задачи, вспомогательная цель, таблица и условия остановки.
  Обозначения согласованы с разделом 1. В его примере получен оптимум
  `(2, 2)` со значением `10` за два ведущих шага.
- При переходе между фазами допустимость определяется по базисным
  искусственным переменным. Если вспомогательная цель оказалась
  неотрицательной при ненулевом остатке, исходные ограничения проверяются
  без пользовательского допуска перед обнулением остатка. Положительная
  погрешность вспомогательной цели при нулевых искусственных переменных
  больше не прерывает решение.
- В среде Ubuntu под WSL выполнены 24 целевые проверки на максимизацию,
  минимизацию, отрицательные правые части, отсутствие ограничений,
  вырожденность, масштабирование, лимит и ошибки ввода. Тест Била завершён
  с оптимумом `1` за семь ведущих шагов. Случай `10⁻¹² x ≤ 1`
  дал оптимум `10¹²`, а `0 x ≤ −10⁻¹²` распознан как несовместный.
- Независимая проверка 10 000 ограниченных задач с целыми коэффициентами
  и двумя или тремя переменными дала совпадение статуса и значения цели
  с точным перебором вершин. Генератор `random.Random(867453)`, расчёт
  вершин в `fractions.Fraction`. На двух плотных входах из серии
  экспериментов подтверждены значения HiGHS `200.82051282051282`
  и `102.97045718513013` с погрешностью менее `4e-13`.

Команды использованной локальной проверки из корня репозитория. Временные
программы лежали в игнорируемом каталоге сборки.

g++ -std=c++20 -O2 -Wall -Wextra -Wpedantic -Iinclude src/simplex.cpp build/agent-2-check/probe.cpp -o build/agent-2-check/probe

g++ -std=c++20 -O2 -Wall -Wextra -Wpedantic -Iinclude src/simplex.cpp build/agent-2-check/driver.cpp -o build/agent-2-check/driver
python3 build/agent-2-check/crosscheck_more.py

Интеграция и коммит переданы агенту 3. Табличный метод использует плотное
хранение и арифметику с конечной точностью. Для плохо обусловленных задач
возможен статус `numerical_failure`.
