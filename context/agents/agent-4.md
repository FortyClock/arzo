# Журнал агента 4

Роль: вычислительные эксперименты, верификация и раздел 4.

## 2026-11-08 — эталонная проверка и раздел 4

- Добавлены восемь контрольных задач LP1, генерация двадцати задач с
  $n=8,16,32,64$ и проверка через SciPy 1.16.3 / HiGHS IPM. Исходные
  файлы, требования и команды описаны в [experiments](../../experiments/README.md).
- Первый прогон на промежуточном ядре выявил численную ошибку фазы I на
  части плотных задач. Агенту 2 переданы два воспроизводимых входа.
  После исправления оба входа и вся серия прошли проверку.
- Финальная конфигурация в WSL: GCC 15.2.0, Python 3.14.4,
  NumPy 2.3.5, SciPy 1.16.3. Команды из корня репозитория:

  ```bash
  cmake -S . -B build/experiments-final -DCMAKE_BUILD_TYPE=Release
  cmake --build build/experiments-final --parallel 2
  python experiments/scripts/run.py build/experiments-final/simplex_cli \
      --output experiments/data/output/results.json
  ```

- Результат: 28 из 28 задач прошли. Сохранены 196 замеров, параметры,
  решения и SHA-256 исходников и исполняемого файла. Максимальное
  нарушение ограничений равно примерно `5.7e-14`, наибольшая абсолютная
  разность цели с эталоном — `2.3e-12`. Пример раздела 1 дал план
  `(2, 2)` и значение 10 за два поворота.
- В `report/sections/04_experiments.tex` внесены методика, контрольные
  исходы, график числа поворотов и фактические измерения. Время включает
  весь вызов CLI, а также разбор результата, и зависит от компьютера.
  Ветка передачи `feature/complete-simplex-project`. Сборку итогового
  отчёта и публикацию проводит интегратор.
