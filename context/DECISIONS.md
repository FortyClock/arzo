# Согласованные решения

## ADR-001 — Инструменты проекта

- Статус: принято, 2026-11-07.
- C++20, CMake >= 3.20, CTest; ядро оформляется отдельной библиотекой.
- Отчёт: LuaLaTeX + `fontspec` + Biber, единая точка входа `report/main.tex`.
- Причина: требования задания и переносимая автоматизированная сборка.

## ADR-002 — Разделение владения

- Статус: принято, 2026-11-07.
- Файлы и роли закреплены в `AGENTS.md` и `TASKS.md`.
- Изменения чужой зоны и утверждённых контрактов выполняются только после
  записанного согласования.

## ADR-003 — Предложение первоначальной нормальной формы API

- Статус: **предложено, не принято**, 2026-11-07.
- Каркас API представляет задачу максимизации/минимизации с ограничениями
  `Ax <= b` и неотрицательными переменными.
- До принятия: агент 1 проверяет соответствие постановке, агент 2 — пригодность
  для алгоритма, агент 3 оценивает влияние на реализацию. Только после общего
  согласования статус меняется на «принято»; до этого реализация не начинается.
