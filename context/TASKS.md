# Распределение задач

Рабочая ветка: `feature/complete-simplex-project`. Состояние относится к
этой ветке. Критерии и результаты приёмки описаны в [REVIEWS.md](REVIEWS.md).

| Ответственный | Результат |
|---|---|
| Агент 1 | Математическая модель, сравнение четырёх методов, пример с рисунком и таблицей, проверка источников. |
| Агент 2 | Двухфазный симплекс-метод, код ядра, алгоритм и особые случаи в разделе 2. |
| Агент 3 / интегратор | Формат LP1, CLI, API и автоматические проверки, раздел 3, титул, сборка PDF. |
| Агент 4 | Входные наборы, сценарий SciPy/HiGHS, исходные измерения, анализ и график в разделе 4. |
| Агент 5 / интегратор | Контроль общей версии, проверка итогового PDF и публикация ветки. |

Перед сдачей ответственный человек дополняет кафедру, группу и ФИО
преподавателя и принимает подготовленную версию.
