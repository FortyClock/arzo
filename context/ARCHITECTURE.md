# Архитектура

## Компоненты

```text
CLI (app/) -> публичный API (include/simplex/) -> ядро (src/)
                                      |              |
                         tests/unit/ -+              +-> tests/integration/
Python experiments/ <-> текстовые форматы из CONTRACTS.md
report/ <- разделы агентов, рисунки, таблицы и references.bib
context/ <- общий контекст и журналы передачи
```

- `simplex_core` — независимая от ввода-вывода C++-библиотека.
- `simplex_cli` — тонкий пользовательский интерфейс; преобразует внешний ввод в
  типы ядра и печатает результат.
- `tests/unit` — проверки отдельных правил/операций ядра.
- `tests/integration` — сквозные сценарии публичного API или CLI.
- `experiments` — Python-сценарии генерации, эталонного решения, сравнения и
  построения артефактов; не является частью runtime C++.
- `report` — единый документ; содержательные разделы подключаются из `main.tex`.

## Направление зависимостей

Ядро не зависит от CLI, Python, LaTeX или тестов. Публичные заголовки не должны
содержать детали UI. Эксперименты взаимодействуют с приложением только через
утверждённый внешний формат. Генерируемые данные не коммитятся без явного
решения о наборе и происхождении.

## Владение

Архитектуру и интеграцию поддерживает агент 3. Предложения других агентов
фиксируются как запрос в их журнале и принимаются через `DECISIONS.md`.
