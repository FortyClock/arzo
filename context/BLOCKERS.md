## Организация работы

- Удалённый репозиторий по умолчанию открывает
  `feature/agent-3-project-bootstrap`. На проверенном срезе эта ветка
  совпадает с `main`. Владельцу репозитория стоит выбрать `main` в качестве
  базовой ветки для новых pull request.
- Роль и порядок передачи замечаний агента 5 нужно закрепить вместе с командой:
  отдельная ветка, техническая рекомендация по приёмке, интеграция через
  ответственного человека. Доступ других участников к публикации веток ещё
  не подтверждён их действиями в Git.
