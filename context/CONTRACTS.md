# Общие контракты

## Математическая модель

Решается непрерывная задача максимизации или минимизации `c^T x` при
`Ax ≤ b`, `x ≥ 0`. Число переменных `n ≥ 1`, число
ограничений `m ≥ 0`. Отрицательные правые части обрабатываются
вспомогательной фазой. Ограничения вида `a^Tx ≥ β` можно
преобразовать умножением на минус один, равенства — парой неравенств.

## C++ API

Объявления находятся в [simplex.hpp](../include/simplex/simplex.hpp).

- `LinearProgram` хранит вектор `objective`, матрицу `constraints`,
  правые части `bounds` и направление. Матрица содержит `m` строк по `n`
  коэффициентов. Число правых частей равно `m`.
- `SolveOptions` содержит положительный конечный `tolerance`
  (по умолчанию `10⁻⁹`) и лимит `max_iterations` (по умолчанию
  `10 000`). Лимит 0 допускает вывод, который можно получить без поворотов.
- `solve(program, options)` не изменяет вход и не выполняет ввод-вывод.
  Поле `iterations` считает завершённые повороты, включая повороты
  вывода искусственных переменных из базиса. Координаты и цель имеют смысл
  только при `optimal`.
- Статусы — `optimal`, `infeasible`, `unbounded`, `iteration_limit`,
  `invalid_input` и `numerical_failure`. Последний обозначает потерю
  численной корректности или невозможность представить результат конечным
  числом в выходном типе.

Входные и выходные значения представлены `double`, промежуточные
вычисления — `long double`. Точность `long double` зависит от компилятора.
Допуск применяется при проверке масштабированного нарушения исходных
ограничений. Для малых коэффициентов, выбора поворота и остановки
действуют правила из раздела 2 отчёта.

## Внешний формат LP1

Пробельные символы разделяют токены. Заголовок содержит `LP1 <направление> m n`
с одним направлением `max` или `min`. Следом идут `n` коэффициентов
цели, затем `m` групп по `n+1` чисел. Первые `n` — коэффициенты строки
матрицы, последнее — правая часть. Дробная часть отделяется точкой,
разрешена научная запись. Лишние токены и бесконечные или неопределённые
числа считаются ошибкой. Пример находится в
[worked-example.lp](../experiments/data/input/worked-example.lp).

`simplex_cli [--tolerance VALUE] [--max-iterations N] [FILE|-]`
читает файл либо стандартный ввод. В stdout выводится объект JSON с
полями `status`, `iterations`, `objective`, `variables`. При
исходе, отличном от `optimal`, цель равна `null`, а массив координат пуст.
Код 2 означает ошибку ввода, код 1 — сбой запуска или выполнения. Остальные
результаты решателя возвращаются с кодом 0. Диагностика идёт в stderr.

## LaTeX

- `report/main.tex` — единая точка сборки.
- Файлы `01_problem.tex` … `04_experiments.tex` содержат по одному
  разделу. Перечень источников формируется из `references.bib`.
- Формулы, рисунки и таблицы имеют уникальные метки `eq:`, `fig:`,
  `tab:`. Ссылки делаются через `\ref` или `\eqref`.
