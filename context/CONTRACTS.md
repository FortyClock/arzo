# Общие контракты

Статус: **интеграционный черновик, не математическое решение**. Он создан только
для компилируемого каркаса. Агент 1 должен проверить постановку, агент 2 —
алгоритмическую достаточность, после чего агент 3 оформляет согласованную версию
отдельным ADR. До этого нельзя считать перечисленные ограничения утверждённой
областью применимости или строить на них несовместимые реализации.

## C++ API

Каноническое объявление находится в `include/simplex/simplex.hpp`.

- `LinearProgram`: вектор коэффициентов целевой функции `objective`, матрица
  `constraints`, правые части `bounds` и направление оптимизации.
- Все строки `constraints` имеют длину `objective.size()`; число строк равно
  `bounds.size()`. На первом этапе каждая строка означает ограничение `<=`, а
  переменные считаются неотрицательными.
- `SolveOptions`: числовой допуск и предельное число итераций.
- `SolveResult`: статус, найденное решение, значение цели и число итераций.
- `solve(program, options)` не выполняет ввод-вывод и не изменяет аргументы.

Предложенные статусы: `optimal`, `infeasible`, `unbounded`, `iteration_limit`,
`invalid_input`. Исключения не используются для штатных математических
исходов; реакция на ошибки программирования отдельно уточняется агентом 3.

## Внешний формат задачи и результата

Формат обмена между CLI и экспериментами пока **не утверждён**. До совместного
решения агентов 2–4 нельзя закреплять несовместимый JSON/CSV/текстовый формат.
Предложение должно включать версию схемы, пример, правила точности и диагностики.

## Численные соглашения

- Все значения runtime представлены `double`.
- Сравнения выполняются с настраиваемым `tolerance`, по умолчанию `1e-9`.
- Вход с NaN/Infinity, несогласованными размерами или неположительным допуском
  возвращает `invalid_input`.
- Правила выбора разрешающего элемента и точные критерии остановки должен
  описать агент 2; после утверждения они добавляются сюда согласованно.

## LaTeX-контракт

- `report/main.tex` — единственная точка сборки.
- Разделы: `01_problem.tex` … `04_experiments.tex`; каждый файл содержит один
  `\section` и не меняет глобальные стили.
- Формулы, рисунки и таблицы имеют уникальные метки с префиксами `eq:`, `fig:`,
  `tab:`; ссылки делаются через `\ref`/`\eqref`.
- Библиографические ключи уникальны и стабильны; источник добавляется только
  после проверки метаданных.
